Políticas de Publicación y Almacenamiento

Separación de Custodia: Git vs. Hugging Face

Para garantizar la máxima velocidad en operaciones de control de versiones, evitar bloat binario en GitHub y asegurar la reproducibilidad abierta con identificadores DOI y versionado de datos DVC/Parquet, el proyecto implementa una estricta segregación funcional entre el repositorio de código fuente (Git) y el repositorio de datos masivos (Hugging Face Datasets).

Instrucciones para Hidratar el Proyecto desde Cero

Para reproducir el proyecto en una máquina limpia, solo se clona el código de Git y se hidrata la carpeta Dataset/ ejecutando el script automático de Hugging Face: 

# 1. Clonar el repositorio Git (código ligero y dashboard)
git clone https://github.com/semillero-agroenso/modelo-predictivo.git
cd modelo-predictivo

# 2. Instalar dependencias exactas
pip install -r requirements.txt

# 3. Hidratar los datos pesados desde Hugging Face Datasets
python Scripts/preparar_huggingface.py --descargar

# 4. Verificar integridad y cero NaNs
python Scripts/auditoria_puntos_2_3_4.py

# 5. Ejecutar suite experimental o abrir el dashboard
python Experimental/ejecutar_experimentos.py
